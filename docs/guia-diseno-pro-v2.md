## Conclusiones cross-video + web (light / dark / mixed)

### 1. ¿Qué hace que un sitio de servicio B2B caro se sienta profesional y de confianza?

Para un **dueño de clínica** (no un developer), “profesional” ≈:

1. **Claridad en <5 s** (PcwuZJNJny4): beneficio concreto, no jerga IA.  
2. **Prueba arriba del fold** aunque no haya clientes: founder con cara/nombre, RGPD/UE, demo live, proceso 3 pasos, trial/garantía (anti-FUD), ciudades (Madrid / US).  
3. **Mostrar el producto** (demo WhatsApp), no vender “la categoría IA” (eco round-1 HUEMOR + Luvoni case study).  
4. **Tipografía serif editorial + sans UI**, whitespace generoso, un solo acento (lujo GmxGdOpzD2w + Bastion + SEEN).  
5. **Layout predecible** (Jacob’s Law): no layouts creativos que asustan a compradores no técnicos.  
6. **Fotos/UI reales** o nada — stock de sonrisas = barato.  
7. **Oro/champagne como acento fino**, nunca fill grande (Bastion: “payday lender” si se abusa del gold).

### 2. Light vs dark vs mixed — veredicto para Atento

| Enfoque | Cuándo ayuda | Riesgo para Atento |
|---|---|---|
| **Dark total (PR #10)** | Productos tech/dev (Linear, Vercel); demos visuales “cinemáticas” | Silvio ya lo rechazó: “demasiado oscuro / no profesional”. NexusBond: healthcare + texto largo → light gana legibilidad; dark asusta a compradores no técnicos. |
| **Light total** | Clínicas (NUYU spa-calm), B2B texto, compliance | Puede verse “genérico médico” si falta contraste y acento premium. |
| **Mixed (recomendado)** | SEEN Kensington: **navy/ink en hero/nav** + **ivory en contenido** + **champagne** en reglas/CTA; bloques producto oscuros solo donde el mock WhatsApp gana contraste | Mejor de ambos: trust clínico light + “producto tech” en isla oscura. |

**Veredicto:** **mixed light-first**. Base ivory/cream (señal salud/confianza). Navy profundo para nav, tipografía y footer. Champagne muted solo en hairlines, iconos y CTAs clave. **Una sola isla oscura** para la demo WhatsApp (no toda la página negra como PR #10).

Luvoni es dark-on-purpose (anti-púrpura IA, demo callback en hero) — válido para SMB escépticos de voz, pero **no** es el patrón de las clínicas premium que Atento quiere atraer como *clientes*. El comprador vive en webs tipo SEEN/NUYU (claras, calmadas). Atento debe **hablar el idioma visual del comprador**, no el de un SaaS developer.

### 3. Estructura de página con cero clientes

Orden concreto (fusiona PcwuZJNJny4 + Luvoni “trust first” + Opux “problema cobertura” + round-1):

1. **Nav mínima** — logo · Cómo funciona · Seguridad · Demo · Contacto  
2. **Hero (light/ivory o navy suave, no black total)**  
   - Badge: “14 días · sin permanencia” + “RGPD / UE”  
   - Headline beneficio: citas/WhatsApp respondido 24/7 para clínicas premium  
   - Sub: USP (protocolo de la clínica + humano en el loop)  
   - CTA primario filled champagne-on-navy o navy-on-ivory  
   - CTA secundario outline  
   - Anti-FUD bajo CTA  
   - Visual: mock WhatsApp (puede ser card oscura)  
3. **Trust strip sin mentir** — “Diseñado para clínicas en Madrid y EE. UU.” · RGPD · “humano puede intervenir” · founder foto (cuando exista) — **cero nº de clientes inventados**  
4. **Problema** (PAS suave): llamadas/WhatsApp perdidos mientras atienden  
5. **Cómo funciona** 3 pasos  
6. **Producto en acción** (isla oscura o card)  
7. **Para quién / para quién no**  
8. **Seguridad** (RGPD, retención, aviso IA)  
9. **Fundador / por qué Atento**  
10. **FAQ** objeciones (“¿suena a robot?”, “¿se integra con mi agenda?”)  
11. **CTA final** + trial
