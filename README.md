# Atento — Recepción con IA para Clínicas Dentales y de Estética

> «Tu recepción con IA, siempre atenta.»

Atento es una solución de recepción con inteligencia artificial para clínicas dentales y centros de medicina estética. Responde en segundos por WhatsApp y web 24/7, orienta a los pacientes con empatía y precisión clínica, pre-reserva citas y realiza seguimiento automático de presupuestos no cerrados.

## 🚀 Características Principales

- **Landing Page moderna y responsive (`/`):**
  - **Hero:** Propuesta de valor clara, imagen principal con foto profesional y accesos directos a demo y WhatsApp.
  - **Problema:** Explicación objetiva de la fuga de pacientes fuera de horario comercial con beneficios cualitativos.
  - **Oferta y Beneficios:** Respuesta inmediata 24/7, agendamiento guiado, follow-up automático, lenguaje clínico natural y handoff humano.
  - **Cómo Funciona:** Proceso de 3 pasos (Diagnóstico → Setup 48-72h → Live con soporte).
  - **Precios Transparentes:** 3 tiers en USD (Esencial $490+$149/mes, Crecimiento $990+$299/mes destacado, Premium $1990+$499/mes).
  - **Casos piloto:** Sección de "Casos piloto en preparación" con CTA a los 3 cupos fundadores.
  - **FAQ:** Preguntas frecuentes en acordeón nativo accesible.
  - **Contacto:** Formulario validado client-side y botón directo de WhatsApp.
  - **Footer:** Aviso reglamentario de proyecto piloto / demo.

- **Demo Interactiva Jugable (`/demo`):**
  - Perfil de la ficticia **«Clínica Dental Aurora»**.
  - Asistente de IA ejecutado 100% en el cliente (sin dependencias ni credenciales externas).
  - Flujo conversacional guiado: bienvenida, detección de tratamientos (limpieza, blanqueamiento, ortodoncia invisible, implantes, valoración estética), rangos de precios orientativos, selección de horarios y confirmación de pre-reserva.
  - Detección de intención humana en cualquier momento con solicitud de WhatsApp para transferir la conversación.
  - Botón de reinicio rápido y respuestas sugeridas.

- **Estrategia Comercial (`PLAN-VENTAS.md`):**
  - Guía detallada para conseguir 20 prospectos en 48h (Google Maps, Meta Ad Library, Instagram).
  - Plantillas de outreach y guion de demo de 15 minutos.
  - Matriz de manejo de objeciones y directrices de privacidad/RGPD.

## 🛠️ Tecnologías y Arquitectura

- **Next.js 15 (App Router)**
- **React 19**
- **Tailwind CSS v4**
- **TypeScript**
- Fuentes del sistema seguras para despliegues autónomos sin dependencia de red externa (`next/font/google` desacoplado).

## 💻 Desarrollo Local

```bash
# Instalar dependencias
npm install

# Correr en desarrollo
npm run dev

# Verificación de lint
npm run lint

# Compilación de producción
npm run build
```
